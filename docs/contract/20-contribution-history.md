# §20. Imported contribution history

Part of the repository contract in [CLAUDE.md](../../CLAUDE.md); equally binding.

Manuscript `origin.contributions` preserves original source identities and
attribution by role: problem, mathematical proof, exposition, formalization or
correction. Each item names contributors, an extracted claim, evidence and scope;
formalization points into an exact Git revision. Source-history predecessors must
exist and form an acyclic graph. This source-declared history is immutable with
the accepted manuscript, hidden with its detailed private projection, and awards
no Mathesis proof or correction credit. Do not infer authors from uploaders or
`createdBy`, generate new contributions for indexing, or equate source-history
links with verified Lean proof use. See `docs/CONTRIBUTION_GRAPH.md`.
