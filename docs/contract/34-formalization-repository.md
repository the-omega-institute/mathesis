# §34. Public formalization content repository

Part of the repository contract in [CLAUDE.md](../../CLAUDE.md); equally binding.

- The organization maintains `formalization` as its own content repository.
  Mathesis/MongoDB/independent receipts remain the authority; this repository is
  an anonymous-public-route projection. PRs, CI, imported sources and curator
  target elaboration confer no verification or credit (§5, §12, §23).
- Snapshot confirmed exact targets, every public verified attempt bundle,
  curator targets and both public leaderboards atomically with the catalog.
  Refuse missing/mismatched target text, source digests or bundle identity.
  Render deterministically offline and cover the whole tree with the existing
  rendered inventory/hash manifest and `check`.
- Generate Lean/Lake environment and complete locks from the verifier inputs
  of the same Mathesis source tree. Frozen generated pin metadata must match
  those inputs. Never hand-maintain duplicate pins or silently upgrade a
  historical target/receipt to the default environment.
- Preserve exact source bytes and original receipts/attribution. Separate proof
  and disproof attempts. Targets share a root name: compile each in an isolated
  module root; never create an aggregate import. Do not execute submitted Lake
  scripts. Document exact build units/commands and what compilation omits.
- Per-node and per-paper indexes distinguish receipt-backed library declarations,
  new Lean, confirmed open targets, no-target-yet with the API reason, and
  disproofs. A paper-level Lean link is not statement-level coverage. Curated
  elaborated targets have their own area and explicitly open no submissions.
- Preserve public leaderboard order/fields and separate paper/conjecture scopes;
  never derive a fresh score from repository content. Counts and snapshot time
  have explicit scopes. Publish the plain statement that this is a projection.
- Expose the trureturing-requests URL and nullable write-back request/state/
  revision fields. Populate only from an explicit public authority; missing
  state remains null. This generator never submits write-back requests.
- Publisher staging/check/sealing precedes all writes. Sync to an existing
  public organization repository with the existing idempotent non-forced
  mechanism, preserving unrelated files. Link from profile and org site.
  Repository creation and publisher credentials stay outside Mathesis.
- CI states checks actually run. Do not assume anonymous access to a private
  base image or claim the prepared library/bundles were compiled when only
  Mathlib targets ran. Historical incompatible targets are explicitly reported.
- The SolveFile store split is design-only in this package; §12/§28/§29's
  identity, lease, source/target, confirmation, privacy, pin, credit and discovery
  invariants remain binding. See [design and migration order](../FORMALIZATION_REPOSITORY.md).
